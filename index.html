Se connecter avec une clé d'accès GitHub

Tes données sont dans le dépôt GitHub privé bw-data. Une clé d'accès permet au site de les lire et de les enregistrer. Elle reste dans ce navigateur.

  1. Crée une clé d'accès sur GitHub.
  2. Dans « Repository access », choisis « Only select repositories », puis bw-data et bw. Le dépôt bw sert à enregistrer ton identifiant.
  3. Vérifie que « Contents » est réglé sur « Read and write ».
  4. Clique sur « Generate token », copie la clé et colle-la ci-dessous.
